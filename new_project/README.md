## Описание проекта

В рамках варианта 23 разрабатывается приложение «Калькулятор счастья».
Пользователь вводит количество сна, кофе, общения, работы и выходных в неделю.
Программа рассчитывает индекс счастья в процентах, строит кольцевую диаграмму
распределения времени и выдает рекомендацию.

Приложение разрабатывается на C++17 с использованием Qt 6 и CMake.
Архитектура проекта строится по паттерну MVC с активной моделью.
