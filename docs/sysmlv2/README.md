# Модели SysMLv2 — InvestLab

- `investlab_context.sysml` — контекст и логическая декомпозиция приложения.
- `investlab_gui.sysml` — структурное описание трёх экранов и элементов GUI.
- Схемы `../figures/context.png` и `../figures/ui_structure.png` являются **визуализацией структуры**, построенной по этой текстовой модели с Graphviz.
- `../figures/setup_screen.png` и `../figures/results_screen.png` — **концептуальные GUI-мокапы**, соответствующие элементам модели, а не скриншоты готовой программы.

**Важное ограничение:** Graphviz не является официальным SysMLv2-рендерером; исходное текстовое описание приведено отдельно. Модель не проходила валидацию в специализированном SysMLv2 IDE/парсере.
