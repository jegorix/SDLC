## Описание проекта

В рамках проекта разрабатывается настольное приложение **«Калькулятор счастья»**.
Пользователь вводит количество сна, кофе, общения, работы и выходных в неделю.
На основе этих данных программа вычисляет индекс счастья в процентах, строит
кольцевую диаграмму распределения времени и выводит рекомендацию.

Приложение должно сохранять введенные данные между запусками и восстанавливать
их при повторном открытии диалогового окна. При вводе некорректных значений,
например если сумма часов превышает 168 часов в неделю, система должна
показывать модальное сообщение об ошибке.
