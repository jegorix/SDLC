# REQ-FUNC-001 — Выбор финансового актива

## Формулировка

Система должна предоставлять пользователю возможность выбрать акцию или ETF из активов, для которых доступны исторические котировки.

## Обоснование

Позволяет построить портфель из интересующих пользователя инструментов.

## Критерии приёмки

- В список портфеля можно добавить не менее одного поддерживаемого актива.
- Выбор инструмента, для которого отсутствуют данные, не приводит к созданию некорректной позиции.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-001; точные ID тест-кейсов будут присвоены при разработке тестов.
