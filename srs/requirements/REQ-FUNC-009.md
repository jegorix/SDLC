# REQ-FUNC-009 — Стратегия RSI

## Формулировка

Система должна моделировать сделки на основании индикатора RSI с настраиваемым периодом и порогами сигнала.

## Обоснование

Позволяет проверить стратегию, использующую оценку импульса цены.

## Критерии приёмки

- Пользователь может задать период RSI и пороги сигнала.
- При допустимых параметрах и достаточных данных система формирует сигналы по выбранным порогам.
- Некорректный порядок порогов отклоняется.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-009; точные ID тест-кейсов будут присвоены при разработке тестов.
