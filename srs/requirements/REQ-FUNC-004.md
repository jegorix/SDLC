# REQ-FUNC-004 — Распределение портфеля

## Формулировка

Система должна позволять распределять начальный капитал между выбранными активами поровну либо по заданным пользователем процентным долям.

## Обоснование

Поддерживает моделирование портфелей с различной структурой.

## Критерии приёмки

- В равномерном режиме доли суммарно составляют 100% с учётом округления отображения.
- В ручном режиме расчёт запускается только при сумме долей 100% в установленной числовой точности.
- Некорректное распределение сопровождается сообщением.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-004; точные ID тест-кейсов будут присвоены при разработке тестов.
