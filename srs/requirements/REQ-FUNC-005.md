# REQ-FUNC-005 — Единая стратегия портфеля

## Формулировка

Система должна применять одну выбранную стратегию ко всем активам портфеля, рассчитывая индикаторы отдельно для каждого актива.

## Обоснование

Упрощает создание сценариев и снижает сложность первой версии.

## Критерии приёмки

- Пользователь выбирает одну стратегию для всего сценария.
- Для SMA/RSI сигналы каждого актива зависят от его собственной истории котировок.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-005; точные ID тест-кейсов будут присвоены при разработке тестов.
