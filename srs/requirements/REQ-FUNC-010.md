# REQ-FUNC-010 — Процентная комиссия

## Формулировка

Система должна учитывать указанную пользователем неотрицательную процентную комиссию при каждой моделируемой покупке и продаже.

## Обоснование

Комиссия влияет на реалистичность финансового результата.

## Критерии приёмки

- При ставке 0% удержание комиссии равно нулю.
- При ненулевой ставке сумма комиссии отражается в итоговой статистике.
- Отрицательные ставки отклоняются.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-010; точные ID тест-кейсов будут присвоены при разработке тестов.
