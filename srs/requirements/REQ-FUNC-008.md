# REQ-FUNC-008 — Стратегия SMA

## Формулировка

Система должна моделировать сделки на основе пересечения двух простых скользящих средних с выбранными пользователем периодами.

## Обоснование

Позволяет изучить механическую стратегию на исторических ценах.

## Критерии приёмки

- Пользователь задаёт два положительных периода с различной длиной.
- При наличии достаточного количества цен система вычисляет линии SMA и определяет сигналы пересечения.
- При недостатке истории система сообщает об ограничении расчёта.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-008; точные ID тест-кейсов будут присвоены при разработке тестов.
