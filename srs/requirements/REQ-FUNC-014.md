# REQ-FUNC-014 — Сводка результата

## Формулировка

Система должна показывать после успешного расчёта начальный и конечный капитал, суммарные взносы, чистую прибыль или убыток и процентную доходность.

## Обоснование

Пользователь должен видеть базовый финансовый итог сценария.

## Критерии приёмки

- Каждый показатель отображается числом с единицами измерения.
- Чистый результат учитывает взносы и модельные комиссии.
- При отсутствии результата сводка не выдаёт фиктивных чисел.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-014; точные ID тест-кейсов будут присвоены при разработке тестов.
