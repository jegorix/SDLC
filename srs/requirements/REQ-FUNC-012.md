# REQ-FUNC-012 — Сохранение портфеля

## Формулировка

Система должна сохранять состав портфеля, распределение капитала и выбранные параметры стратегии в локальном хранилище.

## Обоснование

Уменьшает необходимость повторного ввода сценария.

## Критерии приёмки

- Сохранённый портфель можно повторно открыть.
- После перезапуска приложения сохранённые параметры остаются доступными.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-012; точные ID тест-кейсов будут присвоены при разработке тестов.
