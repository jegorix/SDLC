# REQ-FUNC-015 — График стоимости капитала

## Формулировка

Система должна показывать динамику общей стоимости портфеля по историческим датам моделирования.

## Обоснование

Позволяет визуально оценивать развитие сценария во времени.

## Критерии приёмки

- Для успешного расчёта график содержит временную ось и стоимость портфеля.
- На графике представлены только даты, входящие в выбранный период.

## Метод верификации

**Демонстрация.** Проверка сценария требования REQ-FUNC-015; точные ID тест-кейсов будут присвоены при разработке тестов.
