# REQ-FUNC-003 — Начальный капитал

## Формулировка

Система должна позволять вводить положительную начальную сумму капитала для моделирования.

## Обоснование

Начальная сумма нужна для расчёта количества доступных к покупке активов и стоимости портфеля.

## Критерии приёмки

- Положительная сумма сохраняется в параметрах сценария.
- Нулевая, отрицательная и нечисловая суммы отклоняются с сообщением.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-003; точные ID тест-кейсов будут присвоены при разработке тестов.
