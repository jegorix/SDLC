# REQ-FUNC-016 — Расширенная сводка

## Формулировка

Система должна показывать количество модельных операций, суммарные комиссии и максимальную просадку портфеля.

## Обоснование

Эти показатели помогают оценить затраты на операции и исторический риск.

## Критерии приёмки

- Для завершённой симуляции доступны число сделок, сумма комиссий и максимальная просадка в %.
- Сумма комиссий согласуется с записанными сделками.
- Максимальная просадка неотрицательна при представлении величиной падения.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-016; точные ID тест-кейсов будут присвоены при разработке тестов.
