# REQ-SEC-001 — Отсутствие брокерских операций

## Формулировка

Система не должна отправлять распоряжения о реальной покупке или продаже ценных бумаг и не должна требовать подключения брокерского счёта.

## Обоснование

Исключает несанкционированное выполнение реальных финансовых операций.

## Критерии приёмки

- В интерфейсе отсутствует процедура привязки брокерского счёта.
- При моделировании не выполняются вызовы торговых API для размещения реальных заявок.

## Метод верификации

**Инспекция.** Проверка сценария требования REQ-SEC-001; точные ID тест-кейсов будут присвоены при разработке тестов.
