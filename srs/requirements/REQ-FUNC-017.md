# REQ-FUNC-017 — Обработка отсутствия котировок

## Формулировка

Система должна сообщать о невозможности выполнить расчёт, если необходимые исторические котировки недоступны или не получены.

## Обоснование

Предотвращает неверные результаты и потерю доверия к приложению.

## Критерии приёмки

- При сетевой ошибке выводится понятное сообщение.
- При пустом наборе котировок моделирование не запускается.
- Несохранённые пользовательские параметры не сбрасываются из-за ошибки загрузки.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-017; точные ID тест-кейсов будут присвоены при разработке тестов.
