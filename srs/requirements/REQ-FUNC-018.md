# REQ-FUNC-018 — Проверка доступности исторического периода

## Формулировка

Система должна перед запуском моделирования проверять наличие исторических цен для всех активов портфеля на выбранном периоде и сообщать, какие активы или даты не позволяют выполнить расчёт.

## Обоснование

**Заказчик:** Кузьменков Егор Валентинович (учебный сценарий согласования). Пользователь не должен принимать результаты по неполному историческому периоду за полноценный анализ; проверка снижает риск неверной интерпретации данных.

## Критерии приёмки

- Если для каждого актива доступна история на требуемом интервале, система разрешает запуск расчёта.
- Если отсутствуют обязательные котировки хотя бы одного актива, расчёт не запускается и интерфейс показывает тикер проблемного актива.
- Сообщение указывает, что данные для запрошенного периода неполны или недоступны; приложение не подменяет отсутствующие цены нулями.

## Метод верификации

**Тест.** TC-018: подготовить набор с неполными котировками одного актива; убедиться, что запуск заблокирован и отображён тикер. Для полного набора проверить успешный запуск.

## Дополнительная информация

- Требование связано с BR-003 и BR-005, уточняет REQ-FUNC-002 и REQ-INT-001.
