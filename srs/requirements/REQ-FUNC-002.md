# REQ-FUNC-002 — Выбор периода моделирования

## Формулировка

Система должна принимать начальную и конечную даты исторического моделирования и отклонять период, в котором дата начала позже даты окончания.

## Обоснование

Период определяет границы исторической симуляции.

## Критерии приёмки

- Для корректного диапазона система принимает обе даты.
- Если дата начала позже даты окончания, система сообщает об ошибке и не запускает расчёт.

## Метод верификации

**Тест.** Проверка сценария требования REQ-FUNC-002; точные ID тест-кейсов будут присвоены при разработке тестов.
